# Vídeos

Cada vídeo ganha uma pasta `AAAA-MM-DD-nome-curto/` com:

- `notas.md` — decisões (voz, trilha, arquivos escolhidos, tempos importantes)
- `entrada/` — roteiro aprovado, narração, gravações de tela, prints de referência, trilha escolhida
- `saida/` — vídeo final, GIFs, prévias

O mesmo nome é usado em `remotion/src/videos/<nome>/` (código das animações) e
`remotion/public/videos/<nome>/` (áudios e imagens usados no código).

Vão para o Git: notas, roteiros, narrações e scripts. **Não vão** (pesados ou com dados reais de clientes):
gravações de tela (`entrada/telas/`, `*.mp4`, `*.mov`), `saida/` e `trilhas/`.
