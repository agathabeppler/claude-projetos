# Projetos

Cada vídeo ganha uma pasta `AAAA-MM-DD-nome-curto/` com:

- `entrada/` — narração, gravações de tela, prints de referência, trilha escolhida
- `saida/` — vídeo final, GIFs, prévias
- `notas.md` — decisões (voz, trilha, arquivos escolhidos, tempos importantes)

Esta pasta não vai para o Git (arquivos pesados e possivelmente com dados de clientes).
