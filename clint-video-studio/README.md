# Clint Video Studio

Kit para produzir, com o Claude Code, vídeos de lançamento e GIFs de produto no padrão visual da Clint.

**Comece pelo guia: abra `guia.html` no navegador.**

Resumo:
1. Uma vez por Mac: abra esta pasta no Claude Code e peça "rode o setup" (ou rode `./setup.sh` no Terminal).
2. Para cada vídeo: abra esta pasta no Claude Code, digite `/video-lancamento` e descreva a ideia.
3. Para um vídeo sobre a plataforma (por segmento): digite `/video-plataforma` e diga o segmento.
4. Para um GIF: digite `/gif-produto` e descreva a interação e o tamanho.
